# Student Score Prediction

Task 1 of my machine learning practice. I built a linear regression model that predicts a student's exam score from the hours studied.

## Dataset
Student Performance Factors from Kaggle. Download `StudentPerformanceFactors.csv` from Kaggle and upload it when the notebook asks for it.

## What I did
1. Loaded and checked the data
2. Cleaned the data (removed duplicates, filled missing values, removed scores above 100)
3. Made a scatter plot of hours studied vs exam score
4. Split the data into training (80%) and testing (20%)
5. Trained a linear regression model
6. Evaluated it with MAE, MSE, RMSE and R2
7. Plotted actual vs predicted scores and the regression line

## Tools
Python, Pandas, Matplotlib, Scikit-learn

## How to run
Open `task1_student_score_prediction.ipynb` in Google Colab and run the cells one by one.
